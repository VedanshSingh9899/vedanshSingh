# 📘 Takshshila

Takshshila is a modern web-based learning platform designed to help students select and access educational content efficiently. It includes filters for class, subject, language, and chapter to provide personalized learning experiences.

## 🚀 Features

- 📚 Filter by Class, Subject, Language, and Chapter
- 🌗 Light/Dark mode with persistent theme across pages
- 🧠 Responsive and easy-to-navigate UI
- 🎯 Built for future scalability with modular code

## 🛠️ Tech Stack

- HTML5, CSS3, JavaScript
